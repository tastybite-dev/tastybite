TASTYBITE WEBSITE

HOW TO OPEN
1. Extract TastyBite_website.zip on your laptop.
2. Open the TastyBite folder.
3. Double-click index.html. It should open in Chrome, Edge, or another browser.
4. Keep tastybite-hero.png in the same folder as index.html for the hero background image.

WHATSAPP ORDER FLOW
- On checkout, the page opens WhatsApp with the order summary addressed to +2349113278202.
- The customer must press Send in WhatsApp. The site cannot send a WhatsApp message silently.
- If WhatsApp does not open automatically, use the Send order to WhatsApp button in the confirmation panel.
- The order is not stored in a central database. The WhatsApp message is the way the store receives the order.
- Payment must be verified in PalmPay before treating an order as paid.

IMPORTANT
- This is a front-end website; it does not publish itself to the internet.
- Menu prices are sample prices and can be edited in index.html.
